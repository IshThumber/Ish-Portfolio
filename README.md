# Portfolio Website

A modern, responsive portfolio website built with React, showcasing skills, projects, and experience.

## Features

- **Responsive Design:** Optimized for all devices using TailwindCSS.
- **Lazy Loading:** Components are lazy-loaded for improved performance.
- **Accessibility:** ARIA labels and keyboard navigation support.
- **Consistent Styling:** Global stylesheet for colors, fonts, and utilities.
- **Animations:** Smooth transitions and animations using Framer Motion and GSAP.

## Best Practices

- **Component Structure:** Each component is modular and reusable.
- **Styling:** Use TailwindCSS for consistent styling and responsive design.
- **Accessibility:** Ensure all components are accessible with proper ARIA labels.
- **Performance:** Lazy-load components and optimize images for faster load times.

## Technologies Used

- React
- React Router
- TailwindCSS
- Framer Motion
- GSAP
- EmailJS (for contact form)
